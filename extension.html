How to Install in Google Chrome

📁 Step 1: Identify the Extension Directory

Locate the extension/ folder inside the jobshield codebase folder on your computer.

🌐 Step 2: Open Chrome Extensions Page

Open Google Chrome and navigate to chrome://extensions/ by pasting it into the URL bar and hitting Enter.

⚙️ Step 3: Enable Developer Mode

Toggle the "Developer mode" switch in the top-right corner of the Extensions page to ON.

📦 Step 4: Load Unpacked Folder

Click the "Load unpacked" button in the top-left corner of the page. Select the extension/ folder inside the project directory.

📌 Step 5: Pin and Start Scanning!

Click the puzzle icon in Chrome toolbar, find JobShield, and click the pin icon. You can now select any text on web pages, right-click, and click "Scan with JobShield".
